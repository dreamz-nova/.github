# DreamZ Nova

Nova is a new animation tool started in 2026 by DreamZ, an independent animator from Indonesia, built with Claude Code and AI tools.

- A native Windows 3D animation app for character animators: Minecraft-style rigs today, imported 3D models next.
- Opens existing Mine-imator projects and renders them on a new Direct3D 12 engine.
- In development: an in-app Claude animation assistant (an MCP server today, a direct API integration next).
